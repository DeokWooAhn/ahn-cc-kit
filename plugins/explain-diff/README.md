# explain-diff

코드 변경을 이해하도록 돕는 설명 페이지를 만듭니다. 리뷰 플러그인이 "이 변경이 맞는가"를 판정한다면,
이 플러그인은 "이 변경을 이해했는가"를 돕습니다. 코드를 고치거나 평가하지 않습니다.

```bash
claude plugin install explain-diff@ahn-cc-kit
```

필요한 것은 없습니다. PR을 대상으로 하려면 `gh`가 있으면 편합니다.

## 쓰는 법

"이 PR 설명해줘", "이 브랜치에서 뭐가 바뀐 건지 풀어줘", "방금 작업한 변경 설명 페이지 만들어줘"처럼
요청합니다. `/explain-diff:explain-diff`로 직접 부를 수도 있습니다.

## 페이지 구성

| 섹션 | 내용 |
| --- | --- |
| 배경 | 처음 보는 사람을 위한 넓은 배경(접혀 있음)과 이 변경에 필요한 좁은 배경 |
| 직관 | 작은 예시 데이터와 그림으로 보는 핵심 아이디어 |
| 코드 | 이해하기 쉬운 순서로 묶은 변경 설명과 `파일:줄` |
| 퀴즈 | 객관식 5문항. 고르면 정답 여부와 이유가 바로 나옵니다. 정답이 보기의 위치나 길이로 드러나지 않게 냅니다 |

CSS와 JS가 모두 들어간 HTML 파일 하나라서 외부 요청 없이 열리고, 휴대폰에서도 읽을 수 있습니다.

## 저장 위치

저장소 밖에 둡니다. `EXPLAIN_DIFF_DIR`이 있으면 그 폴더, 없으면 `~/explain-diff/`입니다.
파일명은 `YYYY-MM-DD-<slug>.html`이라 시간순으로 정렬되고 버전 관리에 섞이지 않습니다.

```bash
export EXPLAIN_DIFF_DIR="$HOME/Documents/explain-diff"
```

세션에 비공개 페이지를 게시하는 도구(예: Claude 데스크톱의 Artifact)가 있으면 같은 페이지를 비공개 링크로도
받습니다. 공개로 게시하지는 않습니다.
