# ui-polish

AI가 만든 티가 나는 화면을 제품에 맞게 다듬습니다.
Compose·SwiftUI·Flutter와 한국어 화면을 대상으로 합니다.

## 원본은 unslop 입니다

이 플러그인은 Damir Sokolovsky의 [unslop](https://github.com/heydamir/unslop)(CC BY 4.0)을
**대체하지 않습니다.** 진단 목록과 방향 다섯 줄, 아홉 단계의 순서는 그쪽이 정본입니다.

```bash
claude plugin marketplace add heydamir/unslop
```

```bash
claude plugin install unslop@heydamir
```

원본은 웹 대상입니다(React·Tailwind·HTML·CSS). 모바일에서는 스냅샷 스크립트,
정적 HTML 재구성, 스토리 영상이 돌아가지 않고 토큰 값도 CSS 기준입니다.
**안 맞는 것은 그 셋과 값뿐이고 판단 기준은 그대로 쓸 수 있습니다.**
이 플러그인은 그 위에 보정을 얹습니다. 원본 없이 단독으로도 동작합니다.

## 덜 바꾸는 쪽

**이미 쓰이는 화면에서는 변화 자체가 비용입니다.**

| 상태 | 할 일 |
| --- | --- |
| 징후가 여러 항목에 걸쳐 많다 | 전체 절차 |
| 대체로 정돈돼 있다 | 다듬기 모드 — 진단에서 찾은 것만 |
| 걸리는 게 없다 | **그렇다고 말하고 멈춘다** |

루트 지침에 이미 디자인 규칙이 적혀 있으면 다듬기 모드로 시작합니다.
테마 토큰만 쓰기, 색만으로 뜻을 전하지 않기 같은 규칙이 이미 있다면 심한 슬롭이 아닙니다.

## 알림 훅

새 화면 파일이 생기면 **한 줄로 묻습니다.**

```text
ui-polish: 새 화면 2개가 생겼습니다 (HomeScreen.kt, DetailScreen.kt).
다듬으려면 "디자인 다듬어줘"라고 하세요.
```

**막지 않고 고치지도 않습니다.** 다듬기는 선택이고, 괜찮은 화면을 달라 보이게 바꾸는 것은
개선이 아니기 때문입니다. 판단과 지시는 사람이 합니다.

수정이 아니라 **새로 생긴** 화면만 봅니다. 기존 화면을 한 줄 고칠 때마다 알림이 뜨면
금방 무시하게 되고, 그러면 정작 필요할 때도 안 읽힙니다. 같은 경로는 한 번만 알립니다.

끄려면 `UI_POLISH_DISABLE_SCREEN_NOTICE=1`을 Claude Code 프로세스의 환경에 둡니다.

## ui-contract 와의 관계

```text
디자인을 만든다        →  ui-contract 로 계약을 뽑아 구현한다  →  다듬는다
(pencil 또는 디자이너)     (수치가 틀리지 않게)                    (제품다워지게)
```

디자인이 **있고** 그대로 구현해야 하면 `ui-contract`입니다.
이 플러그인은 **이미 만든 화면**을 다듬습니다. 계약이 있는 화면이면 계약을 먼저 읽고,
계약에 적힌 값을 바꾸는 것은 다듬기가 아니라 디자인 변경이므로 따로 판단받습니다.

## 요구 사항

없습니다. 화면을 띄워 보려면 기기나 시뮬레이터가 있어야 하고, 없으면 건너뛰고
건너뛰었다고 보고합니다. `.pen` 파일을 쓰려면 pen.dev 데스크톱 앱이 실행 중이어야 합니다.
