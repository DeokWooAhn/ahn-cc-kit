# 모바일에서 다르게 읽을 것

원본 절차는 웹 기준이다. 판단 기준은 그대로 쓰고 **확인 방법과 값만** 바꾼다.

## 화면을 어떻게 보나

코드만 읽고 진단하지 않는다. 띄워서 본다.

| 플랫폼 | 방법 |
| --- | --- |
| Android | 실기기가 붙어 있으면 실기기, 없으면 에뮬레이터. 다 쓰면 끈다 |
| iOS | 시뮬레이터. 프로젝트에 이미 쓰는 스크린샷 방법이 있으면 그것 |
| Flutter | 둘 중 붙어 있는 쪽. `flutter run` 뒤 캡처 |
| 공통 | Preview·Compose Preview·SwiftUI Preview 도 쓸 수 있지만 **실제 데이터가 아니다** |

Preview 는 빠르지만 긴 문구·많은 행·실제 폰트에서 어떻게 보이는지는 알려 주지 않는다.
**진단은 실제 화면에서 한다.** Preview 는 고친 뒤 빠르게 확인하는 데 쓴다.

기기가 없으면 건너뛰고 **건너뛰었다고 보고한다.** 코드만 보고 "좋아졌다"고 적지 않는다.

## 웹에 있고 모바일에 없는 것

| 웹 | 모바일 |
| --- | --- |
| `:hover` | **없다.** 눌림(pressed)·포커스·선택 상태로 대신한다 |
| `box-shadow` | Compose `shadow`/`Surface tonalElevation`, SwiftUI `.shadow`, Flutter `BoxShadow`·`Material elevation` |
| CSS `transition` | 플랫폼 애니메이션 API. 길이와 곡선을 토큰으로 둔다 |
| 4px 그리드 | 그대로 쓰되 단위는 dp·pt. 값이 아니라 **배수 규칙**이 요점이다 |
| 뷰포트 폭 | 기기 폭 + **safe area** + 상태바·내비게이션 바 |

## 모바일에만 있는 것

- **터치 타깃.** 시각 크기를 줄여도 누를 수 있는 영역은 줄이지 않는다.
  Android·Flutter 는 48dp, iOS 는 44pt 가 하한이다. 여백을 정리하다 이 선을 깨기 쉽다
- **글자 크기 설정.** 사용자가 키운 글자에서 레이아웃이 깨지는지 본다.
  아이콘 크기까지 따라 커지면 대개 의도가 아니다
- **모션 줄이기.** OS 설정을 켠 상태에서 장식 애니메이션이 꺼지는지,
  그러면서 **로딩 단서까지 사라지지는 않는지** 본다
- **다크 모드.** 토큰이 양쪽에 다 정의돼 있는지, 대비가 남는지
- **한 손 조작.** 주요 행동이 화면 위쪽으로 올라가지 않았는지

## 아홉 단계에서 손볼 곳

**간격** — 같은 역할인데 값이 다르면 먼저 원인을 본다. 공통 컴포넌트를 덮어쓴 것인지,
긴 문구 때문에 다르게 둔 것인지. 이유 있는 예외와 우연한 차이를 가른다.

**색** — 강조색을 한 곳에 모으되 **상태를 전하던 색은 남긴다.**
목록에서 색만으로 상태를 구분하고 있으면 상태 이름이나 표시를 함께 둔다.

**아이콘** — 한 체계로 통일한다. 플랫폼 기본 아이콘 세트와 직접 넣은 자원이 섞여 있으면
크기와 선 굵기가 어긋난다.

**문구** — [korean.md](korean.md)를 읽는다. 줄이되 뜻을 줄이지 않는다.

**글자** — 굵기로만 위계를 만들지 않는다. 크기·색·간격이 함께 움직여야 한다.

**배치** — 실제 데이터로 판단한다. 긴 이름 한 줄, 세 줄, 소수점 있는 수와 없는 수를
같이 넣어 본다. 캡처 한 장에서 균형이 맞는 것과 실제 목록에서 쓰기 좋은 것은 다르다.

**디테일** — 누를 수 있는 것과 없는 것이 구분되는지 본다.
선택된 행·눌린 행·포커스가 있는 행 **셋을 일부러 동시에 만들어** 확인한다.

**비주얼** — 장식을 지운 자리마다 새 이미지를 넣을 필요는 없다.
업무 도구의 완성도는 정렬과 의미 있는 차트에서 나오기도 한다.

**모션** — 피드백에 필요한 것만 남긴다. 대기 중인지 오류인지 알 수 있는 표시가
움직임 말고도 있는지 확인한다.

## 검수

고친 뒤 원래 하던 일을 다시 해 본다. 목록을 거르고 정렬하고 다음 쪽으로 넘어가 본다.

- 기능: 검색·필터·정렬·이동이 원래대로 도는가
- 데이터 상태: 로딩·빈 목록·실패·선택
- 긴 콘텐츠: 긴 이름, 큰 수, 여러 줄 오류 문구
- 폭: 작은 기기와 큰 기기
- 접근성: 글자 크기 키움, 모션 줄이기, 대비
- 범위: 관련 없는 기능·브랜드·절이 바뀌지 않았는가

**돌리지 않은 것은 "통과"가 아니라 "미확인"으로 적는다.**
