# 컴포넌트 매핑

<!-- 디자인 컴포넌트와 코드 컴포넌트를 연결한다. 연결되지 않은 것이 이 작업의 경계다. -->

## 매핑

| 디자인 | 코드 | 비고 |
| --- | --- | --- |
| `<디자인 컴포넌트 경로>` | `<코드 컴포넌트/토큰>` | |

플랫폼마다 코드 쪽이 다르면 플랫폼별로 나눠 적는다.

## 매핑되지 않은 것

<!-- 코드에 대응이 없는 디자인 컴포넌트. 비어 있으면 "없음"이라고 적는다. -->

이 목록에 있는 자리는 **구현하지 않는다.** 새로 만들지도 않는다.
디자인 시스템에 추가할지, 기존 것으로 대체할지는 이 작업 밖의 결정이다.

## 규칙

- 매핑된 컴포넌트를 쓴다. 비슷한 것을 직접 만들지 않는다
- 매핑에 없는 컴포넌트가 필요하면 멈추고 보고한다
- 새 색상 이름·새 폰트 파일을 만들지 않는다
- 코드 컴포넌트가 디자인과 다르게 동작하면(기본 padding, 최소 크기 등) 그 차이를 비고에 적는다
